# Собственные стадии Download 3.4.1

Подготовка материалов, сборка материалов/ZIP и финализация сообщают начало и завершение либо ошибку с прошедшим временем в stderr. Числа resources/model/archives читаются из существующих Maps и массива готовых ZIP; дополнительных inspect, FS-обходов, хешей или getters для отчёта нет. Порядок разрешения материалов, упаковки, записи и final fences сохранён.

Штатный `QUARTO_PROJECT_SCRIPT_QUIET=1` Quarto подавляет новый progress и его часы. Если разрешения не дают прочитать этот флаг, отчёт пропускается; чистая упаковка не получает новых обязательных env permissions. stdout JSON-моста, исходные ошибки и finally сохраняются. Performance ABI не меняется.

Адресные проверки используют настоящую маленькую сборку ZIP через прежние ports, порядок requests/files/save, quiet, исходный отказ записи и недоступный quiet env; native render, exports и grading для логов не повторялись. Это кандидат исходников, не утверждение о текущей установленной композиции или выпуске.

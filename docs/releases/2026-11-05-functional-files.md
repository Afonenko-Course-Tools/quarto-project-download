# Архивы из выбранных файлов Core — 5 ноября

Download упаковывает выбранные Core байты в самостоятельные ZIP. README,
исходники, ресурсы и разрешённые преподавательские файлы проходят с теми же
относительными путями и содержимым. Упаковка не читает исходный проект повторно.

## Что изменилось

Публичная упаковка принимает `ArtifactFiles` через `ArtifactFilesSchema`:
`exerciseId`, `audience` и `files` с `target`, `audience`, `reason`, `bytes`.
Прежний `ArtifactInventory` и его поля `schema`, `operation`, `sha256`,
`rawSource`, `size` не поддерживаются. Размеры ZIP и CRC вычисляются по bytes.
Сохраняются проверки аудитории, безопасных targets и пересечений имён.

Native потребитель передаёт `directories` в `withProjectContracts` и использует
`context.input` как каталог кодового проекта. Служебный `native-input.qmd` не
создаётся. Общие адреса YAML используют явный `base: config`; обычные адреса
остаются относительно конечного кодового проекта. Обычные ресурсы получаются
через `publication.resourceFiles` и `NativeResourceFiles`.

В состоянии временных заявок удалён SHA-256 содержимого. Готовый черновик
публикует собственные bytes без повторного чтения и сравнения заявок. Сохраняются
одноразовая запись, проверки символических ссылок и чужих output collisions,
именной manifest очистки. Последующая узкая дельта убирает оставшийся SHA-1
из технического имени заявки: адрес теперь
`requests/<owner-relative-source>/request.json`. Содержимое source/resources
хранится в JSON; reader проверяет соответствие source пути без сертификата.

Старый тест диагностики импортировал уже отсутствовавший в исходном Source
`prepare`. Он переведён на действующий `finish` и post-hook с сохранением
проверок внешнего процесса, кода завершения и обоих потоков ошибки.

## Проверки и стоимость

Различающий тест упаковки сначала отказал на прежнем reader
`ArtifactInventorySchema`, затем прошёл на функциональном договоре. Пять
проверок сверяют бинарные bytes и CRC, README/src/resources, student/full,
запрещённые пути, collisions, изменение caller memory и SharedArrayBuffer.
Первый измеренный GREEN занял 154 мс без учёта запуска процесса; штатный
Quarto harness также прошёл все пять проверок.

Настоящий native producer с новым каталоговым API создал два ZIP с точными
исходниками. В его журнале подготовка Core заняла 4,6 с, Download — 6,9 с.
Отдельная материализация Core → установленный Download сохранила README,
конечные ссылки, generated resources, имена и байты. Упаковка потребителя заняла
10 мс; предметный loader прочитал 2 YAML/1344 bytes, источники — 5 файлов/183
bytes; планирование — 0 обходов дерева, 5 чтений файлов, 3 запуска Pandoc.
Эти счётчики относятся к малому fixture.

Настоящий native runtime с `resourceFiles`, starter/full и обычным ресурсом,
privacy, разрешениями, одноразовой публикацией и проверкой назначения прошёл
за 118,36 с полного wall-time. Пять адресных наборов diagnostics/archive/
model-artifacts/package-once/model-receipts прошли за 20,01 с полного wall-time.
Проверка ownership отдельно сохранила границы чтения/очистки и соседние файлы.
Ранние полные длительности отдельных запусков не измерялись.

Дополнительная проверка вернула прежний барьер заявок в отдельной копии. Она
отказала после удаления временных заявок с `DOWNLOAD.REQUEST_INVALID` за
126,00 с. Рабочая версия прошла за 167,44 с: ZIP после удаления транспорта
побайтно совпал с подготовленным, последующие проверки разрешений и назначения
также прошли. Это различающая регрессия, а не сравнение производительности.
Штатный byte harness повторён на отдельном checkout frozen Core: 5/5, 2,42 с.

Проверка `contract-types.ts`, `runtime-types.ts`, `package-bytes.ts` на frozen
Core заняла 20,43 с и завершилась 34 ошибками в ещё не обновлённом PL
(`native-adapter`, `native-check-inventory`, `native-check-projection`,
`native-course`, `native-entry`, `native-materialize`, `native-selection`).
Собственных ошибок Download в этом результате нет; весь граф типов пока не
прошёл. После замыкания PL его должен повторить интегратор. Полный `tools/check.sh`
на таком незамкнутом графе не заявляется пройденным; перечислены фактические
адресные запуски.

## Прямые адреса временных заявок

Последующая узкая дельта удаляет SHA-1 producer и соответствующий reader.
`filter.lua` записывает `requests/<owner-relative-source>/request.json`;
`ownership.ts` читает ожидаемые ветви этого же пути и сравнивает JSON source
с адресом. Source остаётся обычным данным. Свежесть, операция или состояние
исходников этим соответствием не удостоверяются.

Каталоги создаются из частей канонического относительного source. Абсолютные,
родительские, неоднозначные пути и обратная косая черта отвергаются. Имя не
кодируется, поэтому длинное кириллическое имя исходника не превращается в
непомещающееся имя файла. Reader отвергает чужие ветви и файлы, старые плоские
имена, несовпадающий source, ссылки и специальные файлы до очистки. Очистка
удаляет проверенные файлы, затем пустые каталоги нерекурсивно.

Новый `request-paths` сначала отказал на прежнем reader за 1,09 с. Проверка
нового reader прошла за 1,18 с; окончательный адресный прогон после добавления
отказа старому плоскому имени — 1,42 с. Настоящий Quarto producer → reader
двух документов, включая длинный вложенный кириллический source, прошёл за
5,16 с без запуска Core или упаковки ZIP. Проверка отказа private NativeRun
после переноса fixture на новый адрес прошла за 5,13 с.

Compiler contract/runtime/request-paths прошёл за 9,85 с на точных Core
`d21ddfdc9e4fde58145275751dccfc1c997777df` и PL
`fcd3320eb6dcbe0fde897ecafafcb9c0b31fb9fc`. Расширение проверки на затронутые
fixtures обнаружило шесть прежних ошибок исторического `tests/native.ts` за
14,05 с: он запрашивал удалённый private API `finish({run,evaluateResources})`.
Этот неканонический тест удалён из активного состава; его действующие замены
сохраняет карта проверок. Повторная компиляция всех оставшихся затронутых
fixtures и runtime прошла за 2,98 с. Заглушки и casts для старого API не добавлялись.

Длинные неизменившиеся ZIP-проверки не повторялись. Java installed copies,
опубликованные пакеты, UI и production этой дельтой не изменялись.

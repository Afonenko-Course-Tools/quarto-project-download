# Диагностика Download

Расширение показывает устойчивый ID, русское пояснение и известный путь,
ресурс, источник заявки или поле. Контекст временного JSON относится к заявке,
а не к номеру строки QMD. Исправьте указанный вход и повторите обычный render.

| ID | Что проверяется | Контекст и действие |
| --- | --- | --- |
| `DOWNLOAD.CONFIG_INVALID` | Форма конфигурации и объявлений ресурсов | ID ресурса и поле; задайте словарь с поддерживаемыми полями. |
| `DOWNLOAD.REQUEST_INVALID` | Shortcode, поля заявки и текущий нативный контекст | Входной документ или файл заявки, ID и поле; согласуйте источник и текущую сборку. |
| `DOWNLOAD.PATH_INVALID` | Граница проекта, каталог и символические ссылки | Путь/поле; выберите обычный каталог внутри проекта. |
| `DOWNLOAD.RESOURCE_UNAVAILABLE` | Неизвестный ресурс, недоступный профиль или проект задания | Источник, ID и профиль; объявите ресурс и согласуйте видимость ссылки. |
| `DOWNLOAD.SELECTION_EMPTY` | Пустой результат отбора | Путь и include/exclude; проверьте шаблоны и .gitignore. |
| `DOWNLOAD.OUTPUT_CONFLICT` | Чужой файл на пути ZIP | Имя и путь архива; выберите свободный путь, сохранив чужой файл. |
| `DOWNLOAD.ZIP_INVALID` | Имена записей и ограничения ZIP32 | Имя и измеренные значения: до 65535 записей и байт имени UTF-8, до 4294967295 байт данных записи и данных с каталогом; сократите имя или разделите большой архив. ZIP64 не поддерживается. |
| `RESOURCE.PRIVATE_OR_SOURCE` | Закрытый материал или авторский/служебный исходник | Путь и выбранный каталог; оставьте публичные стартовые материалы. |

Сообщения Core в опциональном маршруте сохраняют исходный ID и причину.
Download не вводит новую проверку модели и не выдаёт ошибку Core за ошибку ZIP.

Внешний отказ Quarto или Git сохраняет имя инструмента, exit и оба исходных
потока. Невозможность запуска сохраняет причину операционной системы. Неизвестное
исключение сохраняет stack. `git check-ignore` с кодом 1 означает отсутствие
совпадений; stderr при успешной операции не становится авторской ошибкой.

## Корректное подключение

```yaml
project-download:
  resources:
    seminar-data:
      path: /materials/observations
      include: ["**/*.csv", "**/*.md"]
```

Shortcode `{{< project-download seminar-data text="Скачать данные семинара" >}}`
выбирает этот ресурс. Фильтр и native hooks подключаются отдельно, как описано
в README. Для публичного курса используйте `quarto render --fail-if-warnings`;
Download не добавляет собственного режима строгих предупреждений.

Просмотр source показывает текущий документ средствами Quarto. ZIP выдаёт
отобранные материалы; это отдельное действие, а не способ скачать исходник QMD.
